Install Anywhere — Zero Credentials Required

Consume anonymously via Maven Central, Apple SwiftPM, Go Proxy, and GHCR—or launch the Layout Studio and 7-App SDUI BFF in one click.

Gradle BOM & multiplatform artifacts via Maven Central io.github.abeta-dev:bom:0.4.1
build.gradle.kts (commonMain) 
repositories {
    mavenCentral()
    google()
}

dependencies {
    implementation(platform("io.github.abeta-dev:bom:0.4.1"))
    implementation("io.github.abeta-dev:sdui-layout")
    implementation("io.github.abeta-dev:database")        // Optional Room 3 SQLite DB
    implementation("io.github.abeta-dev:watch-companion") // Optional Wear OS / watchOS
}

Published to Maven Central under verified io.github.abeta-dev coordinates while Kotlin source imports remain dev.abeta.kmp.*. Built with official Google AndroidX KMP room3, datastore, lifecycle & savedstate.

Prebuilt Release XCFrameworks via Xcode Swift Package Manager Abeta-dev/kmp-spm
Package.swift — or Xcode → Add Package Dependencies 
// Direct Git URL: https://github.com/Abeta-dev/kmp-spm
dependencies: [
    .package(url: "https://github.com/Abeta-dev/kmp-spm", from: "0.4.1"),
]

// Import prebuilt binary targets directly in Swift:
import AbetaSduiKit   // iOS / iPadOS Compose + SDUI host
import AbetaWatchKit  // watchOS headless wearable companion
