# Platform Host Bridges (`kmp/platforms/`)

Reference OS host glue for targets whose proprietary native toolkits reside outside pure Kotlin/Compose Multiplatform Gradle compilation on non-Android/non-macOS machines:

- **`android/`**: Android phone, tablet & foldable `FragmentActivity` bridge & host templates (`AndroidPlatformBridgeFactory.kt` covering `VibrationEffect` haptics, `ClipboardManager`, `Intent.ACTION_VIEW`, chooser share, `ConnectivityManager` callbacks, AES-GCM `AndroidKeyStore`, `BiometricPrompt`, `ActivityResultContracts` runtime permissions & document picker, push token hook, and `AbetaAndroidHostActivity.kt` demonstrating `enableEdgeToEdge()`, predictive Back `OnBackPressedCallback`, dark-mode & reduced-motion `DesignTheme` propagation, deep links, and `SduiScreen`). Requires Android SDK (`ANDROID_HOME`, `compileSdk >= 35`) inside your Android Gradle consumer module.
- **`wearos/`**: Android Wear OS `ComponentActivity` host (`WearCompanionHostActivity.kt`) wiring `:watch-companion`'s `WatchCompanionController` + `WatchGlancePage` into Wear Compose Material (`ScalingLazyColumn`, `PositionIndicator`, `Vignette`, `TimeText`, disabled non-actionable `Chip`s, and `WearHapticEngine`). Requires Android SDK (`ANDROID_HOME`) + Wear Compose dependencies.
- **`apple/`**: SwiftUI reference hosts (`AbetaAppleHosts.swift`) for **iOS / iPadOS** (`AbetaIosRootAppView`, `AbetaIosSduiScreenView` wrapping `AbetaSduiKit` with `.onOpenURL` and safe-area support), **macOS Cocoa** (`launchMacOsSduiWindow`), and **watchOS** (`AbetaWatchViewModel` + `AbetaWatchSduiView` wrapping `AbetaWatchKit` `createAppleWatchCompanionHost` with Dynamic Type & semantic colors).
